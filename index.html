your games

These sit in the zone list next to everyone else's, and they play in the same window. Only three things are needed: the name, the raw link to the game's html file, and an image for the icon. The rest is optional and only used to sort and filter.
nameraw linkiconkindtags
raw link - the address of the html file itself, the one that ends in .html. Right click the game on github and copy the raw address.
icon - an image address, or a data: link. Square pictures look best.
kind - game, tool, movie, mod or anything else you like. It becomes a filter tag.
tags - comma separated. Also become filter tags, so you can sort by them.
author - whose it is. Optional, shown next to the title.
Anything left empty is simply skipped.
